我已經為您創建了一個完整的 AI 生態系統模擬遊戲！這個遊戲具有以下特色：

## 🎮 主要功能：

1. 虛擬世界環境
- 3000x2000 像素的可滾動大地圖
- 四種地形：草地、沙漠、海洋、森林
- 動態生成的地形分佈

2. AI Agent 系統
- 支援多個 LLM 模型（GPT-4、GPT-3.5、Claude 3、Gemini Pro）
- 每個 Agent 有獨特的名稱、個性和行為模式
- 能量系統（影響行為能力）
- 情緒系統（開心、好奇、疲勞、飢餓等）

3. AI 行為模式
- 探索：在世界中隨機移動探索
- 休息：恢復能量
- 社交：尋找附近的其他 Agent 互動
- 進食：在草地或森林中尋找食物
- 思考：展示內心獨白

4. 互動功能
- Agent 之間會建立關係
- 會說話（顯示對話泡泡）
- 記錄所有互動歷史

5. 控制面板
- 暫停/繼續遊戲
- 調整遊戲速度（1x、2x、5x）
- API 配置（支援 OpenAI、Anthropic、Google AI）
- Demo 模式（無需 API 即可體驗）

6. 即時監控
- 事件日誌：記錄所有重要事件
- 統計資訊：人口數、互動次數、遊戲時間
- Agent 列表：管理所有活躍的 AI

## 🚀 如何使用：
1. Demo 模式（預設）：
- 無需 API Key，直接體驗
- 自動生成 3 個示範 Agent
- 使用預設的行為邏輯

2. 真實 API 模式：
- 選擇 API 提供商
- 輸入 API Key
- Agent 將使用真實的 LLM 進行決策

3. 添加新 Agent：
- 輸入名稱
- 選擇模型
- 可選：描述個性特徵
- 點擊「添加 Agent」

- 漂亮的漸變背景
- 浮動動畫效果
- 對話泡泡動畫
- 顏色編碼的事件日誌
- 響應式設計
